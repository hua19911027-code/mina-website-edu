A4 技術原則（永久適用）

核心原則

  • GitHub 為唯一真實來源：所有程式碼、設定、資料 schema 均在 GitHub Repository
  • Frontend / Backend 完全分離：Frontend 只透過 API 合約與 Backend 溝通
  • Vendor Independent：Cloudflare 可替換、Notion 可替換、Database 可替換
  • AI Provider Independent：AI 服務可替換，不鎖定單一廠商
  • Database Independent：資料層透過 Repository 抽象，可替換底層
  • Deployment Independent：部署平台可替換

強制規則

🚫 Domain 層禁止直接依賴第三方平台 Domain Layer 禁止直接 import 或使用：Cloudflare Workers API、Notion SDK、Supabase Client、OpenAI SDK、Gemini SDK、n8n API。所有外部服務必須透過 Adapter → Provider → Repository 三層抽象。
外部依賴類型正確做法禁止做法
Cloudflare / 部署平台透過 Deployment AdapterDomain 直接呼叫 CF Workers API
Notion / 資料庫透過 Repository → AdapterDomain 直接呼叫 Notion API
AI 服務透過 AI ProviderDomain 直接呼叫 OpenAI/Gemini SDK
平台切換透過 Migration Layer直接修改 Domain 邏輯

Knowledge Search 演算法（V1）

  • 輸入：使用者輸入文字（最多 100 字元）
  • 方法：對 FAQ question 欄位做 substring match（不分大小寫）+ 關鍵字對比
  • 回傳：最多 3 筆相關 FAQ，按相似度排序
  • 閾值：至少一個詞完整包含在 question 或 answer 中，才算命中
  • 沒有命中：觸發 Human Handoff 流程
⚠ V1 限制 V1 Knowledge Search 為簡單字串比對，不支援語意搜尋（Semantic Search）。語意搜尋預留至 V2（需要 Embedding + Vector DB）。

Unknown Question Center

  • 每次 handoff 觸發時，POST 記錄到 backend
  • 記錄內容：問題文字、sessionId、時間戳
  • 後台可查看累積未解問題，補充到 FAQ
  • V1 儲存至 JSON 檔案或 Notion Database

Session 管理（前端）

  • sessionId：前端生成 UUID，存於 sessionStorage
  • 對話記錄：存於 JS 記憶體（頁面關閉即清除）
  • 無後端 session 持久化（V1）

H1 程式碼規範

Frontend HTML 規範

  • 所有頁面使用 lang="zh-Hant"
  • Charset: UTF-8
  • Viewport: width=device-width,initial-scale=1.0
  • HTML5 語意標籤：<header>、<main>、<nav>、<section>、<footer>、<article>
  • Tab 縮排：2 個空格
  • 屬性使用雙引號

CSS 規範

  • 單一 styles.css，不使用 CSS-in-JS
  • CSS Variables 定義在 :root {}，所有顏色/字型從 variable 引用
  • BEM-like 命名（.block-element，不強制 BEM modifier）
  • Mobile-first：基礎樣式給 mobile，用 @media (min-width) 向上擴展
  • 動畫：transition/animation 加 prefers-reduced-motion media query
  • 避免 !important（除非 utility class 才允許）
/* Reduced Motion 範例 */
@media (prefers-reduced-motion: reduce) {
  .blob,
  .sparkle,
  .typing i {
    animation: none;
  }
  .reveal {
    opacity: 1;
    transform: none;
    transition: none;
  }
}

JavaScript 規範

  • Vanilla JS，ES2020+，不引入框架或大型函式庫
  • 模組分離：site.js（通用）、practice.js（題庫）、faq.js（FAQ + Mina）、booking.js（表單）
  • async/await 處理非同步操作
  • 錯誤處理：所有 fetch 呼叫必須有 try/catch
  • DOM 操作：優先使用 document.querySelector，不使用 document.getElementById（保持一致性）
  • 事件監聽：優先使用事件委託（delegation），減少監聽器數量
  • IntersectionObserver：scroll reveal 和 counter 動畫使用
  • 不引入 jQuery

site.js 必須包含的功能

  • Mobile menu（hamburger 開關、backdrop 點擊關閉）
  • Scroll Reveal（IntersectionObserver，觸發 .reveal 元素動畫）
  • Counter Animation（data-to 屬性驅動，進入畫面觸發）
  • Active Nav Link（依當前頁面 URL 判斷，加上 active class）

Backend Node.js 規範

  • TypeScript（.ts），嚴格模式（"strict": true）
  • ESLint + Prettier 強制格式
  • Zod 作為 schema 驗證（Request body validation）
