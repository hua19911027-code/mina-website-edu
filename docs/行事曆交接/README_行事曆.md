# 學年行事曆 — 工程交接說明

頁面：`課程介紹.html`（行事曆在「課程時段一覽」表格下方）
相依檔案：`styles.css`、`site.js`、`assets/`（logo 圖檔）

行事曆是**資料驅動**的：畫面由一份「事件陣列」自動產生，**加幾個節點都不會壞版**——程式會自動依日期排序、分上/下學期、節點上下交錯、軸線自動加長（可左右滑）。

---

## 1. 程式位置

打開 `課程介紹.html`，捲到檔案最底、`<script src="site.js"></script>` 後面那段 `<script>`。
裡面有：

- `render(events)`：把事件陣列畫成行事曆
- `DEFAULT_EVENTS`：目前的示意資料（之後可整段刪掉，改用 Notion 資料）
- 對外掛勾：`window.renderYearCalendar` 與 `window.YEARCAL_EVENTS`

HTML 裡的容器只有一行（不用動）：
```html
<div class="yc-rail" id="ycRail"></div>
```

---

## 2. 一筆事件的資料格式

```js
{
  date:  '2026-06-19',          // 必填，YYYY-MM-DD
  title: '端午節特別活動',        // 必填，節點標題
  desc:  '佳節主題課程與闖關…',    // 選填，卡片說明（可省略）
  type:  'fest',                // 選填，分類（決定顏色）；省略 = 'en'
  sem:   2,                      // 選填，學期 1=上學期 / 2=下學期；省略 = 依月份自動（8~12月＋1月→上、2~7月→下）
  icon:  '🐉'                    // 選填，圓點圖示；省略 = 用分類預設圖示
}
```

> 節點一律**依實際日期排序**。`sem` 用來處理跨界節點——例如 1 月底的寒假營想歸到下學期，就標 `sem:2`。一般節點不必填，會依月份自動分。


### type 分類對照（顏色）
| type   | 意義        | 顏色 | 預設圖示 |
|--------|-------------|------|----------|
| `en`   | 學期・課程  | 粉紅 | 📘 |
| `ex`   | 段考・評量  | 橘   | 📝 |
| `camp` | 營隊        | 藍   | 🎒 |
| `reg`  | 報名・活動  | 黃   | 📋 |
| `fest` | 節慶・活動  | 紫   | 🎉 |

> 端午節、萬聖節這類就用 `type:'fest'`。

## 3. 串 Notion 的兩種接法

**接法 A — 後端先把資料塞進頁面變數（最簡單）**
在那段 `<script>` 之前，輸出一段：
```html
<script>
  window.YEARCAL_EVENTS = [
    { date:'2025-09-01', title:'課輔正式啟動', type:'en' },
    { date:'2026-06-19', title:'端午節特別活動', desc:'…', type:'fest', icon:'🐉' }
    // …從 Notion 整理出來的每一筆
  ];
</script>
```
頁面載入時若偵測到 `window.YEARCAL_EVENTS`，就會用它取代示意資料。

**接法 B — 前端 fetch 後重繪**
```js
fetch('/api/calendar')                 // 你的後端把 Notion 整理成上面的陣列回傳
  .then(r => r.json())
  .then(events => window.renderYearCalendar(events));
```

兩種都行，看你們架構方便。資料筆數沒有上限。

---

## 4. 學期分界（如需調整）

目前依台灣學年自動分組：
- **上學期** = 8 月 ～ 隔年 1 月
- **下學期** = 2 月 ～ 7 月

邏輯在 `aOrder()` 與 `e._ord<=5` 這兩處。若實際學期起訖不同，改這裡即可，跟設計端說一聲也可代為調整。

---

## 5. 注意事項

- 標題／說明已做基本 HTML 跳脫，但仍建議後端先過濾。
- 同月份多筆事件沒問題，會依日期先後並排。
- 整頁其他區塊（課程、營隊、表格）與行事曆無關，可不理會。
