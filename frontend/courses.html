徐薇英文 UP學

英文課程

適合國小一至六年級

徐薇老師精心設計的英文課程，從聽說讀寫全方位訓練，讓孩子在輕鬆愉快的氛圍中，真正建立英文能力，而不只是應付考試。

✓
自然發音系統

從發音規則出發，讓孩子看到生字就會念，不再死背單字。

✓
聽說讀寫四技並重

課堂互動豐富，不只是做題目，真正開口說、動手寫。

✓
文法輕鬆學

生活化情境帶入文法，讓孩子理解規則，而不是死背規則。

✓
小班分組

依程度分組，確保每個孩子都能跟上，也不讓學得快的孩子覺得無聊。

偉智數學 WISE

數學課程

適合國小一至六年級

偉智老師用「理解」取代「死記」，讓孩子真正搞懂數學背後的邏輯。小班制讓老師能掌握每個孩子的狀況，課後有問題也可以問老師。

✓
邏輯思維培養

不只教計算，更教思考方式，建立解題能力。

✓
應用題解題策略

系統化分析題目，讓孩子看到複雜題目也不慌張。

✓
概念深化不死記

從生活情境理解數學，讓公式有意義，而不只是符號。

✓
銜接國中數學

紮實的國小數學基礎，讓孩子進入國中後更有優勢。

課後安親

安親班

適合國小一至六年級

讓家長安心、讓孩子開心。安全舒適的環境，有老師陪伴完成作業，培養自主學習習慣，也照顧孩子的生活起居。

✓
作業輔導

老師協助完成學校作業，有疑問立即解答。

✓
自主學習時間

養成良好的學習習慣，為未來打好基礎。

✓
晚餐點心

貼心準備，讓孩子補充能量再出發。

✓
品格教育

生活教育、人際互動，培養全方位的好孩子。
