隱私權政策

本應用程式（Threads Token App）由臺中市私立卓越國際文理短期補習班開發，僅用於管理本補習班自有的 Threads 官方帳號發文與數據查詢，不對外提供服務，也不蒐集本補習班以外任何第三人的個人資料。

蒐集的資料

本應用程式透過 Threads API 存取以下資料，範圍僅限本補習班自己授權連結的 Threads 帳號：

  • 該帳號的存取權杖（access token）與帳號識別碼
  • 由本應用程式代為發布的貼文內容（文字、圖片、影片連結）
  • 該帳號貼文的公開互動數據（如瀏覽數、按讚數、留言數）

使用目的

上述資料僅用於：

  • 代表本補習班排程、發布 Threads 貼文
  • 讀取本補習班自有貼文的成效數據，供內部分析使用

資料儲存與分享

存取權杖儲存於本補習班自行管理的伺服器環境變數中，不會出售、出租或分享給任何第三方。

資料刪除

如需終止授權或刪除已儲存的存取權杖，可隨時至 Threads／Instagram 帳號設定移除本應用程式的授權，或聯絡下方窗口協助處理。
